DOG BREED FETCHER - VS CODE PROJECT

Files:
- index.html: page structure
- style.css: design/layout
- script.js: fetch logic and breed dropdown

HOW TO RUN:
1. Extract this ZIP file.
2. Open the folder in VS Code.
3. Install the "Live Server" extension (Ritwick Dey), if you don't have it.
4. Right-click index.html.
5. Choose "Open with Live Server".

Internet connection is required because this app uses the Dog CEO API:
https://dog.ceo/dog-api/

The dropdown includes breeds and sub-breeds returned by the API.
Selecting a breed automatically fetches an image.
Click "Fetch Again" to fetch another random image of the selected breed.
